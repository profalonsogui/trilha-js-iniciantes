Condicionais: if / else, switch e ternário

Condicionais fazem o programa tomar decisões: "se isso, faça aquilo; senão, faça outra coisa".

1. if / else if / else

O JavaScript testa as condições de cima para baixo e executa apenas o primeiro bloco verdadeiro.

Na prática: digite uma nota

Esse exemplo já lê um campo da página (você vai estudar isso no tópico de DOM — por enquanto, só observe o if).

2. switch

Ótimo quando você compara uma variável com vários valores exatos. Não esqueça do break!

3. Operador ternário

Um if/else de uma linha só, ideal para escolher entre dois valores: condição ? seVerdadeiro : seFalso.

4. Testando valores "truthy" e "falsy"

Dentro do if você não precisa comparar com true: o próprio valor já é avaliado.

📌 Resumo
  • if / else if / else: só um bloco executa.
  • switch: vários valores exatos de uma mesma variável (use break).
  • Ternário: cond ? a : b para escolhas simples.

🧪 Desafio

Dada a variável hora (0 a 23), mostre "Bom dia" (até 11), "Boa tarde" (12 a 17) ou "Boa noite" (a partir de 18).

Ver uma solução 
const hora = 15;
if (hora < 12) {
  console.log('Bom dia');
} else if (hora < 18) {
  console.log('Boa tarde');
} else {
  console.log('Boa noite');
}
