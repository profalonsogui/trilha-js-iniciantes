Operadores

Operadores fazem contas, comparam valores e combinam condições.

1. Aritméticos e de atribuição

Os de sempre (+ - * /), mais o resto da divisão (%) e a potência (**).

2. Comparação: == vs ===

⚠️ Regra de ouro Use sempre === e !==. O == converte tipos "por baixo dos panos" e gera resultados surpreendentes.

3. Lógicos: &&, ||, ! e ??

  • && (E): verdadeiro só se os dois lados forem verdadeiros.
  • || (OU): verdadeiro se pelo menos um lado for verdadeiro.
  • ! (NÃO): inverte o valor.
  • ?? (nulo): usa o valor padrão apenas se for null ou undefined.
ℹ️ Valores "falsy" (viram falso em testes) false, 0, '' (texto vazio), null, undefined e NaN. Todo o resto é "truthy" (vira verdadeiro).
📌 Resumo
  • % dá o resto; ** é potência; +=, ++ são atalhos.
  • Compare sempre com ===.
  • && e || combinam condições; ?? define padrão para null/undefined.

🧪 Desafio

Dado const n = 17;, mostre no console se n é par (use %) e se está entre 10 e 20 (use &&).

Ver uma solução 
const n = 17;
console.log('É par?', n % 2 === 0);
console.log('Entre 10 e 20?', n >= 10 && n <= 20);
