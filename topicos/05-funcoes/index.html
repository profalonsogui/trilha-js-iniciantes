Funções

Uma função é um bloco de código com nome que você escreve uma vez e usa quantas vezes quiser.

1. Declarando e chamando uma função

Parâmetros são os valores que a função recebe; return devolve o resultado.

2. Três jeitos de escrever

FormaQuando usar
Declaração function nome() {}Funções "principais" do código.
Expressão const nome = function() {}Guardar a função numa variável.
Arrow const nome = () => {}Funções curtas e callbacks (muito comum).

3. Valores padrão e ...rest

Dê um valor padrão ao parâmetro com =. Use ...nome para receber "quantos argumentos vierem".

4. Escopo: quem enxerga o quê

Variáveis criadas dentro de uma função (ou de um bloco { } com let/const) só existem ali dentro.

5. Callbacks e closures

Em JavaScript, funções são valores: dá para passar uma função como argumento (callback) e uma função pode "lembrar" as variáveis de onde nasceu (closure).

📌 Resumo
  • function nome(params) { return valor; }
  • Arrow: (a, b) => a + b — retorno implícito quando não há { }.
  • Parâmetros podem ter valor padrão; ...rest junta o que sobrar.
  • Variáveis de dentro da função não vazam para fora (escopo).

🧪 Desafio

Crie uma função ehPar(n) que retorna true se o número for par, e uma versão arrow dela.

Ver uma solução 
function ehPar(n) {
  return n % 2 === 0;
}
const ehParArrow = (n) => n % 2 === 0;

console.log(ehPar(4), ehParArrow(7)); // true false
