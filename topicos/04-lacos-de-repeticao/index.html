Laços de repetição: for, while e for...of

Laços repetem um bloco de código sem você precisar copiar e colar.

1. for — quando você sabe quantas vezes repetir

Três partes: (início; condição; passo).

Exemplo clássico: tabuada

2. while e do...while — repete enquanto a condição for verdadeira

⚠️ Cuidado com loop infinito Se a condição nunca ficar falsa, a página trava. Sempre garanta que algo dentro do laço muda a condição.

3. for...of e for...in — percorrendo coleções

  • for...of → percorre os valores de um array.
  • for...in → percorre as chaves de um objeto.

4. break e continue

  • continue → pula para a próxima volta.
  • break → sai do laço de vez.
📌 Resumo
  • for: número de voltas conhecido.
  • while: repete até a condição ficar falsa.
  • for...of: valores de arrays; for...in: chaves de objetos.
  • break para tudo; continue pula uma volta.

🧪 Desafio

Some todos os números de 1 a 100 usando um for e mostre o total (resposta esperada: 5050).

Ver uma solução 
let total = 0;
for (let i = 1; i <= 100; i++) {
  total += i;
}
console.log(total); // 5050
