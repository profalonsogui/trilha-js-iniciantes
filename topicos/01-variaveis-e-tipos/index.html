Variáveis e tipos de dados

Uma variável é uma "caixinha com nome" onde você guarda um valor para usar depois.

💡 Como usar esta página Clique em ▶ Executar em cada exemplo. O resultado aparece logo abaixo do código. Para experimentar por conta própria, abra o console do navegador com F12.

1. Declarando variáveis: const, let e var

Use const por padrão. Troque para let só quando o valor realmente precisar mudar. O var é a forma antiga — você vai vê-lo em códigos legados, mas evite em código novo.

2. Os tipos primitivos

Todo valor em JavaScript tem um tipo. Os principais:

3. Convertendo tipos

Valores vindos de formulários chegam como texto. Se você precisa fazer conta, converta antes. Cuidado: o + com texto concatena em vez de somar.

4. Juntando textos com template string

Com crases (`) você escreve variáveis dentro do texto usando ${...}. É bem mais limpo que concatenar com +.

📌 Resumo
  • const (padrão) · let (quando muda) · evite var.
  • Tipos básicos: string, number, boolean, null, undefined.
  • typeof descobre o tipo; Number(), String(), Boolean() convertem.
  • Template string: `Olá, ${nome}`.

🧪 Desafio

Crie as variáveis produto (texto), preco (número) e quantidade (número) e mostre no console: "3x Caneta — total R$ 7.50" usando template string e toFixed(2).

Ver uma solução 
const produto = 'Caneta';
const preco = 2.5;
const quantidade = 3;
console.log(`${quantidade}x ${produto} — total R$ ${(preco * quantidade).toFixed(2)}`);
