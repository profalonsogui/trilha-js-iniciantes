Eventos

Evento é "algo que acontece": um clique, uma tecla digitada, um formulário enviado. Com addEventListener você diz: "quando isso acontecer, rode esta função".

3. Formulário (submit) e preventDefault

Por padrão, enviar um formulário recarrega a página. evento.preventDefault() cancela isso para você tratar tudo com JS.

4. Delegação de eventos (intermediário)

Em vez de colocar um ouvinte em cada <li>, coloque um só na lista e descubra quem foi clicado com evento.target. Funciona até para itens criados depois!

📌 Resumo
  • elemento.addEventListener('evento', funcao) — jeito recomendado.
  • Eventos comuns: click, input, change, submit, keydown, DOMContentLoaded.
  • preventDefault() cancela o comportamento padrão (ex.: recarregar no submit).
  • Delegação: um ouvinte no "pai" + evento.target.closest(...).

🧪 Desafio

Faça um botão que alterna entre os textos "Ligar" e "Desligar" a cada clique.

Ver uma solução 
const botao = document.getElementById('meu-botao');
let ligado = false;

botao.addEventListener('click', () => {
  ligado = !ligado;
  botao.textContent = ligado ? 'Desligar' : 'Ligar';
});
