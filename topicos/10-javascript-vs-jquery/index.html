JavaScript puro vs jQuery

O jQuery é uma biblioteca criada em 2006 para deixar o JavaScript do navegador mais curto e compatível. Hoje o JavaScript moderno faz quase tudo sozinho — mas você ainda vai encontrar jQuery em muito código existente.

ℹ️ Como o jQuery entra na página Basta carregar o arquivo antes do seu script. Neste projeto ele está em assets/js/jquery.min.js: 
<script src="../../assets/js/jquery.min.js"></script>
<script src="script.js"></script>

<!-- ou via CDN: -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
Depois disso, a função $ (ou jQuery) fica disponível: $('seletor') seleciona elementos e devolve um objeto jQuery com métodos encadeáveis.

Tabela rápida de equivalências

TarefaJavaScript purojQuery
Esperar a página carregar document.addEventListener('DOMContentLoaded', fn) $(document).ready(fn) ou $(fn)
Selecionar um elemento document.querySelector('.x') $('.x')
Selecionar vários document.querySelectorAll('.x') + forEach $('.x') (já aplica em todos)
Trocar texto el.textContent = 'oi' $(el).text('oi')
Trocar HTML el.innerHTML = '<b>oi</b>' $(el).html('<b>oi</b>')
Ler/escrever valor de campo input.value $('input').val()
Classes el.classList.add('a') / toggle $(el).addClass('a') / toggleClass
Estilo el.style.color = 'red' $(el).css('color', 'red')
Evento el.addEventListener('click', fn) $(el).on('click', fn)
Criar e inserir createElement + appendChild $(pai).append('<li>…</li>')
Remover el.remove() $(el).remove()
Efeitos (mostrar/esconder) CSS (transition + classe) .show(), .hide(), .fadeToggle(), .slideToggle()
Requisição HTTP fetch(url) $.ajax(), $.getJSON()

Então, qual usar?

SituaçãoRecomendação
Projeto novoJavaScript puro (ou um framework como React/Vue). Menos peso e menos dependências.
Site antigo / WordPress / plugins que dependem de jQueryjQuery continua útil — vale conhecer.
Aprendendo agoraAprenda JS puro primeiro. Quem entende o DOM entende jQuery em minutos.
⚠️ Não misture sem necessidade Um elemento do DOM el e um objeto jQuery $(el) são coisas diferentes: el.textContent funciona no primeiro, $(el).text() no segundo. Para voltar do jQuery ao DOM puro, use $(el)[0] ou $(el).get(0).
📌 Resumo
  • jQuery = atalhos para o DOM: $('seletor').acao(), com encadeamento.
  • O JS moderno (querySelector, classList, fetch) cobre quase tudo que o jQuery fazia.
  • Conhecer os dois ajuda a ler e dar manutenção em projetos antigos.

🧪 Desafio

Reescreva em jQuery: document.querySelectorAll('.item').forEach(el => el.classList.add('ativo'));
