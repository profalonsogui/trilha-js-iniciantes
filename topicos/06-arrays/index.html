Arrays (listas)

Um array guarda vários valores em ordem. Cada posição tem um índice, começando do zero.

1. Criar, acessar e modificar

MétodoO que faz

includes(x) / indexOf(x)Verifica se existe / descobre a posição
join(sep)Junta tudo em um texto

2. Os "quatro grandes": map, filter, find e reduce

Em vez de escrever um for para tudo, estes métodos expressam a intenção:

  • map → transforma cada item e devolve um novo array.
  • filter → mantém só os itens que passam no teste.
  • find → devolve o primeiro item que passa no teste.
  • reduce → "resume" tudo em um único valor (soma, total…).

📌 Resumo
  • Índices começam em 0; length dá o tamanho.
  • push/pop (fim) e unshift/shift (início).
  • map transforma · filter filtra · find procura · reduce resume.
  • [...a, ...b] copia e junta arrays.

🧪 Desafio

Dado const notas = [4, 8, 6.5, 9, 3];, calcule a média e crie um array só com as notas aprovadas (≥ 6).

Ver uma solução 
const notas = [4, 8, 6.5, 9, 3];
const media = notas.reduce((total, n) => total + n, 0) / notas.length;
const aprovadas = notas.filter(n => n >= 6);
console.log(media.toFixed(1), aprovadas); // 6.1 [8, 6.5, 9]
