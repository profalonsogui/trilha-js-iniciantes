Objetos e JSON

Um objeto agrupa informações relacionadas em pares chave: valor — como uma ficha de cadastro.

1. Criar, ler e alterar

Acesse com ponto (pessoa.nome) ou colchetes (pessoa['nome']) — os colchetes servem quando a chave está numa variável.

2. Desestruturação e spread

Atalhos para "tirar" propriedades de um objeto e para criar cópias atualizadas.

3. Object.keys, values e entries

4. Encadeamento opcional ?.

Evita o erro clássico "Cannot read properties of undefined" quando uma parte do objeto pode não existir.

5. JSON: objeto ↔ texto

JSON é o formato de texto usado para trocar dados com APIs e guardar coisas no navegador. JSON.stringify transforma objeto em texto; JSON.parse faz o caminho inverso.

📌 Resumo
  • Objeto = { chave: valor }; métodos são funções dentro do objeto.
  • const { a, b } = obj extrai; { ...obj, a: 1 } copia com mudanças.
  • obj?.x?.y não quebra se algo no caminho não existir.
  • JSON.stringify / JSON.parse convertem objeto ⇄ texto.

🧪 Desafio

Crie um objeto carro com marca, ano e um método descricao() que retorna "Fiat (2020)". Depois converta o objeto em JSON e mostre no console.

Ver uma solução 
const carro = {
  marca: 'Fiat',
  ano: 2020,
  descricao() {
    return `${this.marca} (${this.ano})`;
  },
};
console.log(carro.descricao());
console.log(JSON.stringify(carro)); // métodos não entram no JSON
