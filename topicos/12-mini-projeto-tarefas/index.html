Mini-projeto: lista de tarefas

Hora de juntar tudo: variáveis, condicionais, funções, arrays, objetos, DOM, eventos e JSON — mais o localStorage para guardar as tarefas no navegador.

1. localStorage: guardando dados no navegador

O localStorage guarda pares chave → texto que continuam lá mesmo depois de fechar a página. Como ele só aceita texto, usamos JSON.stringify / JSON.parse para objetos e arrays.

2. O app (já funcionando!)

Adicione tarefas, clique para marcar como feita, use ✕ para remover — e recarregue a página: tudo continua salvo.

    🧠 A ideia por trás do código
    1. Estado: um array tarefas de objetos { id, texto, feita } é a "fonte da verdade".
    2. renderizar(): apaga a lista e desenha de novo a partir do array.
    3. Eventos mudam o array, chamam salvar() e renderizar().
    Esse padrão (estado → tela) é a base de frameworks como React e Vue.
    📌 O que você usou aqui
    • Arrays: push, filter, find, forEach
    • Objetos e JSON: { id, texto, feita }, stringify/parse
    • DOM: createElement, textContent, closest
    • Eventos: submit + preventDefault, delegação de click
    • Funções, condicionais e try/catch

    🧪 Desafios para evoluir o projeto

    1. Adicione um botão "Limpar concluídas" (dica: tarefas.filter(t => !t.feita)).
    2. Adicione filtros: Todas · Pendentes · Concluídas.
    3. Refatore o app usando jQuery e compare com a versão em JS puro (tópico 10).
    4. Permita editar o texto de uma tarefa com duplo clique (dblclick).
