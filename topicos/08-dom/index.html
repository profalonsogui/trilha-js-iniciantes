DOM — manipulando a página

O DOM (Document Object Model) é a página HTML transformada em objetos que o JavaScript consegue ler e alterar.

🌳 Pense numa árvore document → html → body → h1, p, ul → li… Cada tag vira um "nó" que você pode selecionar, mudar, criar ou remover.

1. Selecionando elementos

MétodoRetorna
getElementById('id')Um elemento (pelo id)
querySelector('.classe')O primeiro que combina com o seletor CSS
querySelectorAll('.classe')Todos que combinam (NodeList)

2. Alterando texto, estilo e atributos

  • textContent → troca o texto (seguro).
  • innerHTML → troca o HTML interno (cuidado com dados vindos do usuário!).
  • classList.add / remove / toggle → mexe nas classes CSS.
  • setAttribute / style → atributos e estilos.

3. Criando e removendo elementos

⚠️ Segurança Nunca use innerHTML com texto digitado por usuários (risco de XSS). Prefira textContent ou crie os elementos com createElement.
📌 Resumo
  • Selecione com getElementById, querySelector e querySelectorAll.
  • Altere com textContent, classList, style e setAttribute.
  • Crie com createElement + appendChild; remova com .remove().

🧪 Desafio

Faça um laço que adiciona 3 itens ("Item A", "Item B", "Item C") na lista do palco usando createElement.

Ver uma solução 
const lista = document.getElementById('lista-dom');
for (const letra of ['A', 'B', 'C']) {
  const li = document.createElement('li');
  li.textContent = 'Item ' + letra;
  lista.appendChild(li);
}
